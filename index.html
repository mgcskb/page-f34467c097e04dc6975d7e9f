客户端选择与官方下载

HQExpress 采用通用机场订阅，可在主流加速器中导入。官网不捆绑单一封闭软件，而是按系统给出稳定可用的客户端路径，方便你在电脑、手机和路由器之间切换。

桌面端

Windows 建议使用 Clash Verge 或 v2rayN，导入订阅后开启系统代理即可。macOS 可使用 ClashX Meta 或 Surge，按订阅类型选择 Clash 或单节点配置。Linux 用户可用 Clash Meta / sing-box 命令行或图形前端。

移动端

Android 推荐 Clash Meta for Android，支持订阅自动更新与分应用代理。iOS 可使用 Shadowrocket、Stash 或 Quantumult X，应用需自行通过商店获取，本站提供订阅字段与分流示例，不提供未授权安装包。

路由与进阶

OpenWrt 可用 OpenClash 或 sing-box；旁路网关可直接填写订阅 URL。团队版支持按域名、IP 段做定制路由，把办公系统走直连、跨境应用走加速。

完成套餐开通后，在账户信息中复制订阅地址，打开客户端的“从 URL 更新”或“添加订阅”，粘贴保存并更新节点。首次连接建议选择香港、日本或新加坡节点测试延迟，再按使用场景切换。

操作说明

  1. 在套餐区对照流量、设备数与线路类型，选择基础版、旗舰版或团队版，按月或按年开通。
  2. 开通完成后进入订阅管理，复制 Clash / 通用订阅链接，不要把链接发到公开群组。
  3. 根据设备进入客户端选择：电脑装 Clash 系或 v2rayN，手机装 Clash Meta 或 iOS 商店应用。
  4. 在客户端添加订阅并更新，开启系统代理或 VPN 模式，先用近距离节点确认能打开网页。
  5. 按场景切换：浏览用普通节点，流媒体选解锁节点，游戏切 IPLC。若某节点超时，删除后重新更新订阅。
  6. 流量将尽时提前升级套餐；设备超限会挤占在线会话，团队使用请分配团队版配额。

官方下载与配置说明只出现在本页客户端专区。若有人要求安装来路不明的“加速器安装包”，请停止操作并回到 HQExpress 官网核对。

常见问题

HQExpress 是什么服务？和普通 VPN 有何不同？

HQExpress 是机场订阅型网络加速服务。你购买的是可在多款客户端中导入的节点订阅，而不是单一品牌的封闭 App。这样可以按系统选择 Clash、v2rayN、Shadowrocket 等工具，也能把同一订阅用在路由器上，灵活度高于只提供一个安装包的传统 VPN。

如何完成客户端下载并导入机场订阅？

先在本页客户端专区确认系统对应软件，从该软件的正规渠道安装。然后复制 HQExpress 订阅 URL，在客户端选择“添加订阅/从 URL 更新”，保存后拉取节点列表，开启代理即可。iOS 应用需自行通过商店获取，官网只提供配置方法。

三个套餐该怎么选？流量不够怎么办？

轻度浏览和三台设备以内选基础版；需要原生流媒体、游戏专线或五台设备选旗舰版；工作室、家庭多终端或需要定制路由选团队版。月度流量用尽后加速会受限，可升级到更高档或等待次月重置，按年付只是锁定单价，不改变当月配额。

支持哪些设备同时在线？会不会限速？

基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。超出数量时新会话可能挤掉旧会话。我们按套餐提供相应带宽策略，旗舰与团队的专线节点在高峰期仍优先保障稳定性，但不承诺固定Mbps数值，实际速度受本地宽带和目标网站影响。

能否解锁流媒体，游戏延迟是否更低？

基础版提供基础解锁，满足常见站点的轻量访问。旗舰版强调全节点原生流媒体解锁，并带 IPLC 游戏优化；团队版在此基础上增加高带宽 VIP 节点。游戏请优先连接标注专线或优化的节点，并用客户端规则只代理游戏进程，避免把更新下载也走加速流量。

如何确认这是 HQExpress 官网，客服怎么联系？

请核对浏览器地址与本页品牌名称、套餐价格是否一致。官方只通过站内工单处理旗舰版优先支持和团队版客户经理服务。不要向陌生账号发送订阅链接或验证码。若页面出现评分星级或伪造用户评价，即可判断并非本站风格。
